Meu water cooler Digoo veio sem software

Sim, o water cooler Digoo vem sem software para a telinha (ou com um programa fraco). A solução grátis é o Digoo LCD Studio: ele acha a tela sozinho e mostra temperatura da CPU/GPU, GIFs, vídeos e a música que está tocando.

⬇ Baixar grátis para Windows

Esse programa serve para o meu?

Serve se a sua tela usa o painel HONGTAI / LOVINGCOOL "MONITOR", que é o que vem na maioria dos watercoolers Digoo, LovingCool e de marcas parecidas. Para conferir: abra o Gerenciador de Dispositivos do Windows e veja se aparece uma porta COM com o ID 33c3:7791 (ou 7788 / 7792).

Como instalar

  1. Baixe o zip na página de download e extraia em qualquer pasta.
  2. Ligue o water cooler no USB e abra o DigooLCD.exe. A tela é encontrada automaticamente.
  3. Escolha um tema na aba Temas.
  4. Para ver a temperatura da CPU, instale o driver grátis PawnIO pelo botão na aba Sensores.

Não precisa instalar Python nem nada. Para abrir junto com o Windows, marque "Iniciar junto com o Windows" na aba Configurações.
